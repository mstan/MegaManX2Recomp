# Coverage and correctness survey, 2026-10-18

ROM CRC32: `947B0355`. SHA-256: `f3246755f608a1e1dc9c848b61da3b824c7853b29b3be40df6fc7f2793a887ed`.

Framework: snesrecomp `b8945554` (PR #183), with recursively updated main/master dependencies. Generation policy lives in `recomp/generate.toml`; `tools/regen.sh` delegates to the framework. The recipe applies to developer regeneration and the launcher SDK. Generated C is never edited by hand or committed.

The checkpoint directory and stage variables were checked against the original USA ROM and Myriachan's Rockman X2 Practice sources. The original full loader clears checkpoint $1FB4 at $00976C; writing a checkpoint before it runs does not select that checkpoint. Instruction breakpoints at $009FE9 allow a RAM-only edit after that reset, before the original graphics selector. Enable both SNESRECOMP_ENABLE_TRACE and SNESRECOMP_REVERSE_DEBUG for this diagnostic build. Production defaults keep instruction instrumentation off.

Earlier 127-capture trials did not establish 127 checkpoints: their loader reset the selector. The speculative +10-variant coverage profile was withdrawn. No newly harvested profile is adopted in this release. Special records with a zero Y coordinate require additional prerequisites and are excluded from ordinary-spawn claims.

Adaptive widescreen requires a wide host window. Enabling the mod in a 640x480 window still produces 256-pixel gameplay. Use a 1280x720 window and verify the screenshot width; earlier such 4:3 captures are not widened-renderer evidence.

The corrected fresh-boot survey sampled twelve nonzero-Y checkpoints across stages $01-$0C, with the original graphics loader, selector readback, movement and shooting. All twelve completed and produced 342-pixel captures. These include ordinary and optional-room approaches, rather than twelve certified boss defeats. The instrumented build supplies diagnostic coverage only; no performance comparison is drawn from its instruction hooks.

Reference walkthrough: https://gamefaqs.gamespot.com/snes/588480-mega-man-x2/faqs/23574

Automated runs use a dummy output audio device while preserving audio emulation. Release defaults retain normal audio. Private ROMs, full memory captures, journals, and trial profiles remain outside the repository. A successful build or version string alone is not evidence of cross-build netplay compatibility.
